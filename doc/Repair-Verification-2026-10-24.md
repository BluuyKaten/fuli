## 验证范围和部署注意

- 后端覆盖 H2 持久化、真实 trade HTTP 入口、JWT/内部密钥过滤链和 Feign 合约；没有启动 MySQL/Nacos 与全部服务做完整联调。
- 前端单测运行真实 Vue 组件模板和事件，图表 API 使用模拟对象；另完成真实浏览器与生产包的固定接口交互验收。浏览器测试没有连接真实后端行情，不能代替全部服务的端到端联调。
- 练习数据库升级使用 `sql/practice.sql`（只新增表、可重复执行）；尚未对本机已有 MySQL 应用迁移。新库 `sql/trade_db.sql` 已包含练习表。练习只支持已同步A股未复权日线，固定费用与简化撮合口径见规则，不模拟分红、滑点或涨跌停排队。
- 前端仍有已有的静态/动态导入混用警告，主 JS 包约 3.10 MB（gzip 974 KB）；构建成功，体积优化未纳入本轮正确性修复。
- auth、trade、analysis 与网关需使用同一 `JWT_SECRET`；内部调用端需使用同一 `INTERNAL_KEY`。内部查询路径有变更，相关公共接口调用端需同步部署。
- 资金仍采用异步最终一致性；本轮确保业务失败不伪报成功、补偿可重试，没有改为同步资金预占模型。
- 持仓重建修复适用于系统允许删除的该股票最后一笔交易，不会自动改写既有历史错账。成本计算沿用现有不计费用的持仓均价口径。
- 全新数据库初始化及已有数据卷的区别见 [README](../README.md)。不要对已有数据直接重跑会重建表的初始化脚本。
