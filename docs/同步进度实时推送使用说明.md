# 同步进度实时推送使用说明

## 功能概述

股票日线数据同步支持**异步执行 + 实时进度推送**,前端可以通过 **SSE (Server-Sent Events)** 监听同步进度,配合进度条展示。

## 核心特性

| 特性 | 说明 |
|------|------|
| 异步执行 | 同步任务在后台线程执行,接口立即返回任务 ID |
| 实时推送 | 通过 SSE 实时推送进度,无需轮询 |
| 幂等同步 | 已同步过的交易日(数据 >= 4000 条)自动跳过 |
| 限速控制 | 每分钟最多 400 次请求(Tushare 限制 500 次) |
| 异常通知 | 失败时推送详细错误信息 |

## API 接口

### 1. 启动同步任务

**请求**:
```http
POST /data/tushare/sync/daily-by-date-range
Content-Type: application/json

{
    "startDate": "20250101",
    "endDate": "20250331"
}
```

**响应**:
```json
{
    "code": 200,
    "data": "SYNC1722931200000"
}
```

**参数说明**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| startDate | String | 是 | 起始日期,格式 yyyyMMdd |
| endDate | String | 是 | 结束日期,格式 yyyyMMdd |

**校验规则**:
- 日期格式必须为 yyyyMMdd
- 起始日期不能晚于结束日期
- 日期范围不超过 400 天

---

### 2. SSE 监听进度(推荐)

**请求**:
```http
GET /data/tushare/sync/progress/{taskId}
Accept: text/event-stream
```

**响应事件流**:
```
event: progress
data: {"taskId":"SYNC1722931200000","status":"RUNNING","percent":25,...}

event: progress
data: {"taskId":"SYNC1722931200000","status":"RUNNING","percent":50,...}

event: progress
data: {"taskId":"SYNC1722931200000","status":"COMPLETED","percent":100,...}
```

**进度数据结构**:

```json
{
    "taskId": "SYNC1722931200000",
    "status": "RUNNING",           // PENDING/RUNNING/COMPLETED/FAILED
    "startDate": "20250101",
    "endDate": "20250331",
    "totalDays": 65,
    "processedDays": 30,
    "successDays": 28,
    "skippedDays": 2,
    "failedDays": 0,
    "totalCount": 140000,
    "currentDate": "20250215",
    "percent": 46,
    "message": "同步 20250215 完成,新增 5000 条",
    "startTime": "2025-08-06T14:00:00",
    "endTime": null,
    "errorDetail": null
}
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| taskId | String | 任务唯一标识 |
| status | String | 任务状态: PENDING/RUNNING/COMPLETED/FAILED |
| startDate | String | 起始日期 |
| endDate | String | 结束日期 |
| totalDays | Integer | 总天数 |
| processedDays | Integer | 已处理天数 |
| successDays | Integer | 成功天数 |
| skippedDays | Integer | 跳过天数(数据已存在) |
| failedDays | Integer | 失败天数 |
| totalCount | Integer | 同步数据总条数 |
| currentDate | String | 当前正在同步的日期 |
| percent | Integer | 进度百分比 0-100 |
| message | String | 当前提示信息 |
| startTime | String | 开始时间 |
| endTime | String | 结束时间 |
| errorDetail | String | 失败详情(仅 FAILED 状态) |

## 前端集成示例

### 使用 EventSource (推荐)

```javascript
// 1. 启动同步任务
const response = await fetch('/data/tushare/sync/daily-by-date-range', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        startDate: '20250101',
        endDate: '20250331'
    })
});
const result = await response.json();
const taskId = result.data;

// 2. 监听进度
const eventSource = new EventSource(`/data/tushare/sync/progress/${taskId}`);

eventSource.addEventListener('progress', (event) => {
    const progress = JSON.parse(event.data);
    console.log(`进度: ${progress.percent}%`);
    console.log(`状态: ${progress.status}`);
    console.log(`消息: ${progress.message}`);
    
    if (progress.status === 'COMPLETED') {
        console.log('同步完成!');
        eventSource.close();
    }
    
    if (progress.status === 'FAILED') {
        console.error('同步失败:', progress.errorDetail);
        eventSource.close();
    }
});

eventSource.onerror = () => {
    console.error('SSE 连接错误,切换到轮询模式');
    eventSource.close();
    startPolling(taskId);
};
```

### 使用轮询(备选)

```javascript
const startPolling = (taskId) => {
    const timer = setInterval(async () => {
        const response = await fetch(`/data/tushare/sync/progress/${taskId}/status`);
        const result = await response.json();
        const progress = result.data;
        
        console.log(`进度: ${progress.percent}%`);
        
        if (progress.status === 'COMPLETED' || progress.status === 'FAILED') {
            clearInterval(timer);
        }
    }, 2000);  // 每 2 秒查询一次
};
```

## 注意事项

1. **SSE 超时**: 默认 30 分钟超时,超时后需要重新连接
2. **任务数据保留**: 任务完成后数据保留 5 分钟,之后自动清理
3. **并发限制**: 建议同时运行的同步任务不超过 3 个
4. **网络环境**: SSE 需要保持长连接,某些代理服务器可能会中断连接,此时会自动切换到轮询模式

---

## 常见问题

**Q: SSE 连接断开怎么办?**
A: 前端可以监听 `onerror` 事件,切换到轮询模式。

**Q: 任务数据多久清理?**
A: 任务完成后 5 分钟自动清理,请及时获取最终结果。

**Q: 可以取消正在执行的任务吗?**
A: 当前版本暂不支持取消,后续版本会添加取消功能。

**Q: 同步失败如何处理?**
A: 查看 `errorDetail` 字段获取失败详情,修复问题后可以重新同步失败的日期范围。
