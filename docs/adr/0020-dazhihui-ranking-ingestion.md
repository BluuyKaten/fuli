# 使用大智慧原生复制命令采集人气

用户已明确目标列为“人气{wyz}”，并给出人工“常用 → 复制到剪切板”的路径。当前运行实例来自 `F:\dzh365(64)`，其列表配置把“人气(wyz)”绑定到 `OBV1.1` 的日周期输出；旧 `Z:\dzh2` 的调查不能外推到当前实例。

Java 服务在已登录的本机 Windows 桌面调用内置助手。助手从程序菜单资源解析复制命令，异步投递给目标主窗口，等待剪贴板序列更新并核对拥有者和人气表头后取表。该方式避开分辨率和坐标依赖，且读取的是软件已经计算的指标。

本地文件解析仍是可选后续路线：目前只确认了公式映射，尚未解码目标指标的数值缓存；活动 SST 的共享冲突不代表数据没有落盘。当前实现不宣称直接解析了专有文件。
