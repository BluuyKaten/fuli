## 已确认规则（首轮 Q1–Q7）

1. Q1：画线、添加买点、添加卖点三种工具互斥；切换保留已有线和标记；Esc 退出当前工具。
2. Q2：用户手动操作交易练习，系统负责推进行情、模拟成交和复盘。
3. Q3：指定股票与日期，展示起点之前的一段行情；练习过程中逐根揭晓后续 K 线。随机抽样和隐藏股票名称留待后续。
4. Q4：看完当天走势后作决定，推进到下一交易日时才知道实际开盘成交价。不能看完当天走势后按当天价回填成交。
5. Q5：练习资金、持仓、买卖点和画线只属于本次练习，与原账户及其他练习完全独立。
6. Q6：复盘展示账户收益率、同期买入持有收益率、最大回撤、交易费用和完整走势上的逐笔成交点。明确展示账户与基准的差距，不用事后最高最低价直接判定对错。
7. Q7：允许浏览已揭晓历史；不允许撤回成交或退回过去改决定；重新练习保留为另一条记录。


## 已确认规则（第二轮 Q8–Q12）

用户于第二轮全部选择推荐口径，以下为本次实现规则：

- Q8 行情与训练模型：首版只做 A 股日线，使用 data_db 已同步的未复权行情，不切换到东方财富前复权；无记录日期不生成 K 线、不调用其他数据源，并明确提示无法区分停牌与数据缺失。数据无效或相邻已存行情的前收盘价相对前一根收盘价断层超过 0.5% 时拒绝该区间；不模拟分红送转。采用明确标注的简化训练规则：100 股整数倍、按模拟交易日执行 T+1、无成交量或一字线时不成交，其余按下一交易日开盘撮合；不还原涨跌停排队和滑点。
- Q9 资金与费用：起始资金默认 100,000 元，可创建时修改；固定训练费率为双向佣金万三、每笔最低 5 元，卖出印花税万五，金额四舍五入到分；不计其他费用。规则在练习创建时锁定，明确不是历史费率还原。
- Q10 委托：输入固定股数；同一时点最多一笔待成交委托，推进前可撤销或替换；按下一根日线开盘尝试全额成交，资金或可卖股数不足则整单拒绝并说明原因，不部分成交、不自动追单。例如 10 万元账户周一按 10 元估算买 9,000 股，周二开盘 12 元导致资金不足，不能偷偷用周一价格成交或自动缩量。
- Q11 样本与结束：选择起止日期，起点是最初可见行情的截止日，默认提供起点之前最多 120 根日线作为分析背景，背景不计入收益区间。每次揭晓一根可用行情，终点自动结束，也允许提前结束；结束撤销未成交委托，剩余持仓按最后已揭晓收盘价计值而不强制卖出。复盘揭晓所选区间完整走势。
- Q12 基准与评价口径：账户与基准收益均算到实际结束日；基准从起点之后首个符合相同成交限制的交易日开盘买入并持有，使用同样初始资金、整手限制与买入费用，保留零头现金，未发生的卖出不扣费用；没有可成交日或资金不足一手时保持现金。最大回撤按每日收盘总资产（现金加持仓市值）计算。提前结束时，之后揭晓的行情仅供复盘，不再改变当次收益与回撤。

两轮已确认，无未决业务分支。实现使用创建时冻结的行情快照与版本校验；同一版本的重复操作不再次推进或成交，返回冲突后重新读取练习。

## 实现前已核实的技术边界

以下是代码事实与隔离要求，接口字段和数值口径见[练习接口契约](2026-10-24-practice-api.md)：

- 日线查询：`DataFeignClient.getDailyData(String stockCode, String startDate, String endDate)` 支持服务端日期区间；`StockDataController.getDailyData` 按股票代码等值匹配，日期使用 `yyyyMMdd` 字符串并按升序返回。同步保存的是带交易所后缀的代码（如 `600519.SH`），创建练习需统一代码与日期格式，不能直接传图表显示用的纯数字代码。
- 数据归属：data-service 实际使用 `data_db`，日线有 `(stock_code, trade_date)` 唯一键。同步接口直接映射 OHLC、参考前收盘价、成交量和金额，没有保存复权因子、历史 ST/板块状态、交易日历或分红事件。SQL 定义成交量单位为手、成交额为千元；练习股数不能直接当成成交量单位。
- 数据稳定性：同步会按股票与日期更新已有行情；保存继续时必须维持同次练习使用的行情口径与数据版本，不能因后台重同步悄悄改写已经揭晓的价格或成交结果。
- 未来数据：普通 `/stock/daily` 允许不传结束日期；普通分钟/周/月线会经过 `StockDataRouterService` 自动回退数据源。东方财富实现固定 `fqt=1&end=20500101`，不能以此前复权全量数据作为盲测前缀，再仅靠页面隐藏后半段。
- 新的练习读接口只接受练习标识，并从可信登录身份与服务端保存的进度决定可见范围。客户端不得通过传 `endDate`、游标或股票代码扩大范围；推进应原子处理委托与新增可见行情，防止双击/重试造成重复成交或跳过决策时点。
- 前端自动取数：`LightweightChart.loadData` 挂载、换股和换周期时取全量行情，再把相同数据送入图表、指标和信息面板。`useIndicators` 的纯指标函数可用于已知前缀，直接复用整个普通图表则会触发外部取数。`KLinePage` 把最后一根价格交给正式 `TradePanel`；该面板读取真实 profile/可卖量并向 `/trade` 录入当前日期的正式交易，不能用于练习委托。
- 前端实时入口：`OrderBookPanel` 挂载后读取 `/stock/quote` 并通过 `useRealtimeQuote.onQuote` 建立 `/ws/quotes` 当前行情订阅；`WatchlistPanel` 读取最新价格。练习展示组件需要只消费会话允许的数据，不能挂载这些自动请求。
- 标记与缓存：`useTradeMarkers` 自动读取不带截止日期的正式交易；`useDrawingTools` 使用 `kline_drawings` 下仅按 `stockCode|period` 区分的本地缓存，并与正式后端画线合并。练习图表不能复用这些数据源或回退缓存；标注需按认证用户与本次练习隔离。`currentStockInfo` 和 `lastViewedStock` 也是普通图表全局状态，不能覆盖练习绑定的股票。
- 复盘边界：结束前不得返回待揭晓的 OHLC、未来指标输入、预加载图表数据或完整行情下载；结束后的揭晓响应仍要校验练习归属。其他练习的成交和标注不能混入本次。

## 验证目标

- 对跨用户查询和按 ID 修改、删除建立回归验证；内部统计查询仍可正常工作。
- 资金业务失败不得标记消息成功；正向与反向资金操作均可持久化重试。
- 删除最后一笔交易后持仓数量与成本能准确恢复。
- 前端生产构建通过；图表使用当前库支持的 API，绘图与标记工具不串模式。
- 盲测期间，行情响应、指标输入、导出、买卖标记、画线、实时推送与统计都不能暴露尚未揭晓的走势。结束后按确认的规则展示复盘。

### 盲测实现后的验收场景

| 场景 | 必须验证的结果 |
|---|---|
| 新建与恢复练习 | 首次响应和重新打开只含截止当前进度的行情；背景不进入成交与收益区间 |
| 伪造进度、股票或用户参数 | 不能扩大可见行情、访问他人练习或改变他人成交；归属从登录身份确定 |
| 周一作决定、周二开盘成交 | 周一下单回执不含周二价格；周二推进后才出现实际成交和该日行情 |
| 重复推进与网络重试 | 不重复成交、不越过一个以上决策时点；失败回滚资金、成交和进度 |
| 刷新、重登与后台重同步 | 当前进度和既有成交保持一致，同次练习的已知行情不被静默改写 |
| 独立账户与标注 | 操作练习不会改变正式现金、持仓、交易或普通图表标注，也不影响另一练习 |
| 查看已经揭晓的历史 | 只能浏览；不能在过去补单、撤回成交或通过切换图表日期改变当前决策日 |
| 图表与指标 | 指标只计算可见前缀；不连接实时行情、不拉取最新报价或正式交易，不向浏览器预载未来行情 |
| 完成或提前结束 | 停止推进和下单，按确认口径冻结结果，再开放本次区间完整走势用于复盘 |
| 手工核算 | 使用小型固定行情逐笔核对现金、股数、费用、净收益、基准、超额收益和收盘最大回撤 |

数值验收使用初始资金100000元的固定小样本：买入100股、次日开盘11元、买佣金5元，现金98895元；收盘12元时权益100095元。再次提交卖单，下一日开盘13元成交，佣金5元、印花税0.65元，最终现金100189.35元，总费用10.65元。买入持有基准首次买9000股、佣金29.70元、留现金970.30元；12元收盘时权益108970.30元。
