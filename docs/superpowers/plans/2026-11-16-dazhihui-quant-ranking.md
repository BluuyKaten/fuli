# 大智慧人气自动采集实施记录

## 目标

在复利系统中自动取得大智慧“人气{wyz}”列以及最新价、涨幅等指标，保存每日快照，汇总每天前二十名的上榜次数，并提供企业微信通知配置。

## 已落实

- [x] 独立量化排行页面、每日指标数据表和历史总表。
- [x] 原生菜单复制助手：解析程序菜单资源、检查剪贴板序列和拥有者、验证人气表头、原子写临时文件。
- [x] Java 服务直接调用助手，页面手动采集接口、每用户自动配置与最近运行结果。
- [x] 北京时间 15:10 调度、服务启动补跑、同日成功去重、五分钟间隔且每天最多三次自动重试。
- [x] 严格按人气数值降序重算排名，负数正常参与，同值以代码升序确定名次。
- [x] 未计算值显式跳过并计数；缺列、日期冲突、非空畸形值和全部未计算拒绝覆盖旧快照。
- [x] 保留股价和全部原始指标，重复列名追加编号，历史仅统计人气前二十名。
- [x] 自动配置数据库迁移 V18，并已执行到本机数据库。
- [x] HTTP 集成测试、排行/自动化测试、前端测试与构建、本机真实大智慧采集验证。

## 当前限制

- 大智慧需要已登录并打开目标行情列表，Windows 桌面未锁定。
- 默认只跳过周末；节假日通过环境变量配置，未接入在线交易日历。
- 企业微信地址需在页面配置；现场验证不向外发送消息。
- 直接文件读取只确认公式 `OBV1.1` 映射，尚未完成数值缓存解码。
