# 股票复盘系统 - 开发进度

## 技术栈

- **后端**: Spring Boot 4.1.0 + Spring Cloud 2025.1.2 + Spring Cloud Alibaba 2025.1.0.0
- **ORM**: MyBatis-Plus 3.5.17 (`mybatis-plus-spring-boot4-starter`)
- **认证**: JJWT 0.13.0 (JWT, HMAC-SHA256, secret >= 256 bits)
- **数据库**: MySQL (每个服务独立数据库)
- **前端**: Vue 3 + Vite + TypeScript + Ant Design Vue + ECharts
- **服务注册**: Nacos (可选，不运行时不影响本地开发)

## 项目结构

```
fuli/
├── common-api/          # 公共模块 (Result, 异常, 实体基类)
├── gateway-service/     # 网关服务 (端口 8080)
├── auth-service/        # 认证服务 (端口 8081, 数据库 auth_db)
├── trade-service/       # 交易服务 (端口 8082, 数据库 trade_db)
├── analysis-service/    # 分析服务 (端口 8083, 数据库 trade_db 只读)
├── data-service/        # 数据同步服务 (端口 8084, 数据库 trade_db)
├── frontend/            # 前端项目 (端口 3000)
└── sql/                 # 数据库脚本
    ├── auth_db.sql
    ├── trade_db.sql
    └── analysis_db.sql
```

## 服务间通信

trade-service 通过 Feign 调用 auth-service 的现金操作接口：

```java
@FeignClient(name = "auth-service")
public interface AuthFeignClient {
    @PutMapping("/auth/internal/deductCash")
    Result deductCash(@RequestParam Long userId, @RequestParam BigDecimal amount);

    @PutMapping("/auth/internal/addCash")
    Result addCash(@RequestParam Long userId, @RequestParam BigDecimal amount);
}
```

## 注意事项

1. **Spring Boot 4.x 变更**:
   - 移除 `bootstrap.yml`，改用 `spring.config.import=optional:nacos:`
   - 使用 `mybatis-plus-spring-boot4-starter`

2. **JWT Secret**: 必须 >= 32 字节 (256 bits)，通过环境变量 `JWT_SECRET` 配置

3. **Nacos**: 不运行时不影响本地开发，但服务注册会失败

4. **股票数据**: 需要预先导入 `stock_daily_data` 表数据

5. **环境变量**: 敏感配置（JWT_SECRET、DB_PASSWORD、INTERNAL_KEY）通过环境变量或 `.env` 文件配置，参见 `.env.example`

## 启动方式

### 方式一：Windows 本地启动（无需 Docker、无需 Nacos）

**前置条件**：
- 安装 [MySQL 8.0+](https://dev.mysql.com/downloads/installer/)（必须）
- 安装 JDK 17+
- 安装 Maven 3.8+
- 安装 Node.js 18+
- Redis（可选，用于 JWT 黑名单）

**步骤**：

```bash
# 1. 初始化数据库
# 打开 MySQL 命令行或 MySQL Workbench，执行：
source sql/auth_db.sql
source sql/trade_db.sql

# 2. 设置环境变量（PowerShell）
$env:JWT_SECRET="your-256-bit-secret-key-here-must-be-at-least-32-characters-long"
$env:DB_USERNAME="root"
$env:DB_PASSWORD="123456"
$env:INTERNAL_KEY="your-internal-key-here"

# 3. 启动后端服务（按顺序，每个服务一个终端）
# 注意：不启动 Nacos 时，需要设置服务地址环境变量
$env:AUTH_SERVICE_URL="http://localhost:8081"
$env:TRADE_SERVICE_URL="http://localhost:8082"
$env:ANALYSIS_SERVICE_URL="http://localhost:8083"
$env:DATA_SERVICE_URL="http://localhost:8084"

mvn -pl auth-service spring-boot:run
mvn -pl trade-service spring-boot:run
mvn -pl analysis-service spring-boot:run
mvn -pl data-service spring-boot:run
mvn -pl gateway-service spring-boot:run

# 4. 启动前端（新终端）
cd frontend
npm install
npm run dev
```

### 方式二：使用 Nacos（可选）

如果你希望使用服务注册中心（可选）：

1. 下载 [Nacos](https://github.com/alibaba/nacos/releases)
2. 启动 Nacos：`startup.cmd -m standalone`（Windows）
3. 无需设置 `*_SERVICE_URL` 环境变量，网关会自动从 Nacos 发现服务

### 方式三：Docker Compose（可选）

```bash
docker-compose up -d
```

## Windows 常见问题

### 1. 端口被占用

```powershell
# 查看占用端口的进程
netstat -ano | findstr "8080"
# 终止任务
taskkill /PID <pid> /F
```

### 2. MySQL 连接失败

确认 MySQL 服务已启动：
```powershell
net start MySQL80
```

### 3. 环境变量不生效

PowerShell 中设置的环境变量仅在当前会话有效。永久设置：
```powershell
[Environment]::SetEnvironmentVariable("JWT_SECRET", "your-secret", "User")
```

或编辑 `.env` 文件（需要手动在代码中读取，或使用 `dotenv` 库）。

### 4. Nacos 启动失败

Nacos 是可选的。如果不启动 Nacos，服务注册会失败但不影响业务功能。
如需启动 Nacos，可下载 [Nacos Windows 版](https://github.com/alibaba/nacos/releases)：
```bash
startup.cmd -m standalone
```
